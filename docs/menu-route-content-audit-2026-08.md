# Wakation 메뉴·라우트·콘텐츠 깊이 감사

- 감사일: 2026-08-01
- 기준 브랜치: `feat/content-commerce-depth-audit-v1`
- 기준 Production commit: `af4215a`
- 페이지 엔트리: `src/app/**/page.tsx` 126개
- 검증 언어: KO / EN / JA

## 1. 감사 방법

1. `src/lib/navigation.ts`의 모든 내부 경로를 실제 `page.tsx`와 대조했다.
2. Production을 390×844 viewport에서 직접 열어 주요 허브의 제목, 링크·버튼 밀도, 이미지 사용, 가로 overflow를 확인했다.
3. 페이지 파일이 짧더라도 실제 View 컴포넌트가 풍부한 경우 단순 파일 크기로 낮게 평가하지 않았다.
4. 페이지의 역할을 `발견 → 여행지 이해 → 준비 → 프로그램 → 저장` 순서로 분류했다.
5. 변동성이 큰 법률·가격·일정은 공식 출처와 확인일이 없으면 ‘콘텐츠 깊이’가 아니라 ‘신뢰 위험’으로 처리했다.

## 2. 메뉴 경로 결과

`npm run audit:menu-routes` 기준 71개 Navigation 목적지가 실제 정적 또는 동적 라우트로 해석된다. 이미지 경로는 메뉴 경로 감사에서 제외하고, `[city]` 같은 동적 세그먼트는 실제 파일 존재 여부로 확인한다.

| 1차 메뉴 | 고객 역할 | 핵심 도착지 | 판정 |
| --- | --- | --- | --- |
| 여행 찾기 | 아직 목적지를 정하지 않은 사용자 | Trip Match, Collections, Stories, 도시 비교 | 유지 |
| 여행지 | 지역을 비교·이해 | Destinations, Guide | 유지 |
| 여행 준비 | 외부 제휴 상품과 실용 준비 | Select, 숙소, 체험, eSIM, 교통 | 유지 |
| 프로그램 | Wakation 직접 운영·참여형 | Hosted, 지역 지원, 국내·해외 체류 | 유지 |
| 저장 | 재방문 | Trip Match, 지원사업, 제휴 상품 | 범위 설명 보강 |

## 4. 구현한 6개 우선 라우트군

1. 성장·학습: `/learn`, `/select/learn`
2. 브랜드 신뢰: `/about`, `/report/yangyang`, `/hosted`, `/select`
3. 비자·체류 안전 정보: `/visa-ai`
4. 에디토리얼 발견: `/stories` 및 연결된 Story 상세
5. 재방문: `/wishlist`
6. 문의·책임 범위: `/contact`

## 5. 현지화 원칙

- 영어와 일본어는 한국어 문장 길이를 그대로 옮기지 않고 카드·Hero 줄 수에 맞춰 별도 문장으로 작성했다.
- 일본어 메뉴의 `旅を探す / 行き先 / 旅の準備 / プログラム / 保存 / その他` 구조는 유지한다.
- 비자·체류 문구는 세 언어 모두 ‘추천 비자’보다 ‘공식 자격 재확인’을 먼저 전달한다.
- `/stories`의 고객 용어는 ‘워케이션 스토리’보다 범위가 명확한 `여행 이야기 / Travel stories / 旅のストーリー`로 정리했다.

## 6. 운영 기준

- Navigation 경로 변경 시 `npm run audit:menu-routes`를 실행한다.
- 이번 우선 라우트의 가짜 예정 상품, 외부 hotlink, 출처 없는 비자 단정이 재도입되지 않도록 `npm run audit:content-depth`를 실행한다.
- 공개 이메일은 `wakation.sf@gmail.com`만 사용한다.
- Hosted와 외부 제휴 상품은 카드, CTA, 문의 안내에서 항상 분리한다.
