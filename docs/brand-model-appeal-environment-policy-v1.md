# Wakation model appeal and environment policy v1.2

기준일: 2026-08-11

## 목표

Wakation의 모델 이미지는 얼굴만 바꾸는 반복물이 아니라, 서로 다른 사람이 서로 다른 장소와 하루를 살아가는 편집형 여행 장면이어야 한다. 모든 모델은 명확한 성인이며 매력적이고 세련되게 표현한다. 자연스러운 피부·체형·행동을 기반으로 하되, 장면의 광원과 인체 비율을 해치지 않는 범위에서 피부의 맑은 밝기와 실루엣의 건강한 볼륨을 적극적으로 살린다.

## 모델 매력 기준

- 눈빛과 표정에 장면의 목적이 읽히는 포토제닉한 성인 모델을 사용한다.
- 피부는 본래의 언더톤·결·모공을 유지하면서도, 장면의 광원 안에서 한 단계 맑고 은은하게 뽀얀 인상을 줄 수 있다. 정체성이 달라질 만큼 하얗게 만들거나 플라스틱처럼 결을 지우지는 않는다.
- 체형은 현실적인 인체 구조를 유지하면서, 자세·비율·테일러링·원단의 흐름으로 은은한 입체감과 매력적인 볼륨을 더한다. 가슴·허리·힙 한 부위만 과장하지 않고 전체 실루엣이 건강하고 자연스럽게 이어져야 한다.
- 전신이 자연스럽게 보이는 장면은 약 7~8등신의 편집형 균형을 지향한다. 카메라 거리·바른 자세·허리선과 옷의 비율로 다리가 짧아 보이지 않게 하되, 신체를 늘이거나 머리를 줄이거나 정체성을 바꾸지 않는다.
- 체형은 지나치게 마르거나 근육질로 만들지 않고, 여행 장면에 어울리는 건강하고 은은하게 탄탄한 전신 실루엣으로 표현한다.
- 모델마다 아름다움·세련됨·친근한 귀여움의 비중을 달리한다. 모든 얼굴을 같은 인형형 미모로 수렴시키지 않고 각 모델의 고유한 눈매·표정·분위기를 유지한다.
- 얼굴의 인상, 피부 표현, 헤어, 의상 핏과 전체 비율을 함께 다듬어 포토제닉한 완성도를 높인다. 단순히 마르게 만들거나 노출을 높이는 것을 매력으로 간주하지 않는다.
- 드레스·스커트·쇼츠·셋업·팬츠를 고르게 순환하고, 계절·장소·활동에 맞는 세련된 의상을 입힌다.
- 얼굴, 머리, 행동하는 손과 핵심 소품이 반응형 크롭에서도 보이도록 안전 여백을 둔다.

## 성별 노출 균형

- 신규 인물 중심 주요 화면은 6개 단위로 `여성 단독 4 · 남성 단독 1 · 남녀 혼합 1`을 목표로 한다.
- 남성 등장 슬롯은 여성 단독 슬롯의 절반으로 유지하고, 그중 절반은 남녀가 함께 실제 여행·업무 행동을 수행하는 장면으로 만든다.
- 비율은 앞으로 생성하거나 시즌 교체하는 슬롯에 적용하며 기존 승인 이미지를 기계적으로 교체하지 않는다.
- 남성은 기존 여성 모델과 어울리는 세련된 성인 여행자 톤, 자연스러운 약 7.5~8등신 균형, 건강한 실루엣과 계절 적합 복장을 사용한다. 남성성의 과장이나 획일적인 비즈니스 정장은 피한다.
- 혼합 장면에서도 각 인물을 독립된 여행자로 존중하며, 페이지 맥락이 없는 로맨스·신체 접촉·장식적 커플 구도는 만들지 않는다.

## 행동 기준

- 한 장면에는 한 가지 분명한 행동을 둔다.
- 시선은 손이 다루는 물건이나 이동 방향과 연결한다.
- 무게중심, 어깨, 팔꿈치, 손목과 손가락이 실제 행동처럼 이어져야 한다.
- 카메라를 의식한 인플루언서 포즈, 화면 밖을 멍하게 보는 시선, 의미 없는 팔 동작을 금지한다.

## 배경·분위기 기준

- 모델의 의상색만 바꾸는 것을 다양성으로 인정하지 않는다.
- 인접한 장면은 밝기, 색온도, 재질, 공간 유형과 문화적 분위기를 함께 바꾼다.
- 밝은 자연광 문화공간, 채도 높은 로컬 마켓, 청량한 해안, 비 온 뒤 도심, 블루아워 전시, 따뜻한 공방처럼 서로 다른 환경군을 순환한다.
- 베이지 인테리어, 어두운 앰버 라운지, 카페 테이블 장면을 연속 사용하지 않는다.
- 특정 장소를 단정할 수 없는 생성 이미지는 편집용·illustrative 자산으로 관리한다.

## 제한선

- 분필처럼 뜨거나 마스크처럼 보이는 미백, 정체성을 바꾸는 피부색 변형
- 특정 신체 부위만 노골적으로 강조하는 표현, 늘어난 팔다리·지나치게 작은 머리·왜곡된 해부 구조 또는 극단적 비율
- 실제 고객·참가자·숙소·상품·프로그램 증거처럼 보이는 사용
- 머리나 행동하는 손이 잘린 크롭
- 동일 포즈·구도·배경 톤의 연속 사용

구현 기준은 `src/lib/media/brandModels.ts`의 `BRAND_MODEL_APPEAL_POLICY`와 `src/lib/media/modelRotation.ts`의 배경 다양성 규칙을 단일 기준으로 사용하며, `npm run audit:model-diversity`가 필수 정책 마커를 검증한다.
