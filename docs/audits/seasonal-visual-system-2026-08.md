- Home의 Mood 카드는 모든 카드가 같은 크기라 편집 우선순위가 보이지 않았고, Duration의 `1주일·2주·한 달` 이미지가 각각 다낭 숙소·발리·크루즈로 연결돼 기간의 의미와 일부 맞지 않았다.
- 상품 카드 fallback은 숙소·스테이·워크스페이스가 같은 이미지로 반복됐다.
- 기존 Home에서 Ken Burns와 티커를 포함한 무한 모션이 동시에 존재했으나, 사용자가 느끼는 생동감보다 장식적 움직임에 가까웠다.

## 적용 내용

1. Home Hero를 7초 무음 MP4 루프로 교체했다.
   - Desktop 1920×1080, 약 1.2MB
   - Mobile 1080×1920, 약 1.0MB
   - LCP는 기존 정지 poster가 담당하고 영상은 700ms 뒤 로드한다.
   - `Save-Data`와 `prefers-reduced-motion`에서는 정지 poster만 표시한다.
   - 5초를 넘는 자동 모션이므로 재생·일시정지 버튼을 제공한다.
2. WAK-MODEL-F의 늦여름 골든아워 장면을 새로 제작하고 Media Manifest에 출처·제약·계절을 기록했다.
3. Mood 영역은 첫 카드를 2×2로 키운 편집형 리듬으로 바꿨다.
4. Duration 이미지를 여행 기간의 실제 의미에 맞게 다낭·치앙마이·발리 도시 이미지로 교체했다.
5. 상품 카드의 숙소·스테이·워크스페이스 fallback을 서로 다른 편집 자산으로 분리하고 채도·대비를 회복했다.
6. 장식 목적의 `animate-pulse`를 제거했다.

## 수동 검토 순서

1. `/` Desktop: 첫 7초 동안 A → F → J 전환, 검색 카드 가독성, 우측 영상 제어
2. `/` Mobile: 인물 얼굴·가방·손의 크롭, 세로 영상의 전환, 360px overflow
3. `/en`, `/ja`: 계절 라벨과 재생 버튼 접근성 문구, 일본어 줄바꿈
4. Mood: 첫 카드가 과도하게 크지 않은지, 나머지 7개 카드가 탐색 가능한지
5. Duration: 1주일=다낭, 2주=치앙마이, 한 달=발리 이미지가 맥락에 맞는지
6. `/select/*`: 카드 fallback 반복 감소와 이미지 농도
